# Career Compass｜实习准备助手

面向第一次准备实习的大学生的可操作 Web 原型，聚焦“我现在最应该先准备什么”。

## 快速演示（无需安装）

使用 Chrome 或 Edge 直接打开根目录下的 `index.html`。不要使用 Internet Explorer，因为它会拦截本地 JavaScript。

## Docker 启动

```bash
docker compose up --build
```

浏览器访问：<http://localhost:5173>

停止服务：

```bash
docker compose down
```

容器只提供 Nginx 静态前端，不包含后端、数据库、真实 AI 模型或外部服务。

## 演示信息

- 建议设备：桌面端，1440×900 或以上
- 预设角色：林同学，信息管理与信息系统专业
- 预设目标：数据分析实习生
- 重置方法：刷新浏览器页面
- 无需账号、密码或模型额度

## 推荐演示路径

1. 在“今日计划”检查或修改目标、阶段、专业和称呼。
2. 点击“生成我的准备建议”，观察生成中状态。
3. 在建议页点击三条建议，查看对应依据和下一步。
4. 点击“修改信息”，演示纠正系统理解。
5. 点击“开始行动”，先取消一次，再重新进入并确认。
6. 点击“有帮助”或“不太适合”提交反馈。
7. 进入“准备记录”，查看进行中事项和准备度变化。
8. 返回首页，点击“演示：AI 建议生成失败”，展示失败与重试。
9. 清空目标后提交，展示信息不足状态。

## 交付文件

- `index.html`：完整可操作原型入口
- `src/app.js`：交互与模拟业务规则
- `src/styles.css`、`src/static.css`：视觉与响应式样式
- `PRODUCT_DESIGN.md`：用户、依据、范围取舍、流程、规则和指标
- `PAGE_STATES.md`：编号后的页面与关键状态清单
- `TEST_REPORT.md`：验收案例与已知边界
- `Dockerfile`、`docker-compose.yml`：容器启动配置

## 核心指标

首次进入用户在 5 分钟内确认开始 1 个具体行动。

过程指标包括档案完成率、建议查看率、行动确认率和建议反馈率。详细口径见 `PRODUCT_DESIGN.md`。

## 真实性说明

原型中的建议和准备记录均为标明的演示数据，不代表真实访谈、模型结果或业务增长数据。当前版本只验证交互闭环与产品判断。
